# Resources — Python Bytes

This is the **Resources** book: the collection of material accumulated in this repo over
roughly ten years. Unlike `Curriculum/`, this is not a teaching sequence — it is a library.

Two jobs live here:

1. **Consolidation.** There is a lot of redundancy. The same topic (e.g. the duck/wolf
   pursuit problem) recurs in several places. The goal is to find every occurrence of a
   topic, pick a single canonical home (often one dedicated markdown file), and retire the
   duplicates — always consulting Rob before merging or deleting.
2. **Logical organization.** Arrange the material so it is browsable and each piece earns
   its place, in the spirit of a Martin Gardner book. Non-coding material (poetry,
   philosophy, program-operation notes) is welcome here.

> Resources may contain anything the club has touched: coding and non-coding alike. The repo
> is named `othermathclub` for legacy reasons; the club is **Python Bytes**, and the
> `Curriculum/` book is specific to it. Resources has the latitude to be broader.
