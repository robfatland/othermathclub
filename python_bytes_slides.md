# Python Bytes
## A Math + Coding Club for Middle School

---

## What Is Python Bytes?

- Weekly 90-minute sessions for 6th and 7th graders
- Learn Python programming through mathematical exploration
- Non-competitive: curiosity and creativity, not contests
- ~50 students across four classrooms

---

## The Philosophy

> "Start with an idea. Think about it. Come up with a calculation.
> Only then open your laptop and start writing code."

- Code is a **tool for exploring ideas**, not the goal itself
- Every topic has a **surprising punchline** that motivates the coding
- We balance drill, discovery, and delight

---

## What Students Learn

### Python Fundamentals
- Variables, loops, functions, libraries
- Problem-solving through code
- Debugging and experimentation

### Mathematical Thinking
- Fractals and self-similarity
- Number sequences (Fibonacci)
- Randomness and probability
- Geometric patterns

## A Typical Session

| Time | Activity |
|------|----------|
| 0–5 min | Kinesthetic warm-up (away from laptops) |

---

## Sample Punchline: The Chaos Game

- Pick three points (vertices of a triangle)
- Start anywhere. Repeat: pick a random vertex, jump halfway there, draw a dot.
- **Expected result**: a random cloud of dots
- **Actual result**: the Sierpinski Triangle — a fractal!

Students are *surprised* into wanting to understand why.
