# One-line and two-line programs


What do these Python programs do? Predict first! Then try it out to see if you got it. If one does *not* work: Don't worry, it is *supposed* to not work!


```
print(3)

print('3')

print('sandwich')

print(sandwich)

sandwich = 6
print(sandwich)

print(sandwich + 2)

print(sandwich/2)

shake = 7
print(sandwich + shake)

print(0%2)

print(1%2)

print(2%2)

print(3%2)

print(4%2)

# notice the pattern
print(5%2)

print(4%3)

print(5%3)

print(6%3)

print(11%6)

print(17%5)

print("Once upon a time")

print('Once upon a time')
print('  there was a pig')
```
