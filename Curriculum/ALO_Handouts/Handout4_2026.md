# Handout 4 if Logic


We know `print()` and `for i in range(3):` and `turtle`. Now it is time to use logic. Write each program, predict what it will do, run it and see what happens. Then cross it off and keep going until you have done them all. This one is double-sided; there are a few more on the back.
<br><br>

```
if True: print("it was true")
else: print("it was false")

if 1: print("it was true") 
else: print("it was false")

if 0: print("it was true") 
else: print("it was false")

if 2: print("it was true") 
else: print("it was false")

if 3 > 2: print("it was true") 
else: print("it was false")

if 2 > 7: print("it was true")

else: print("it was false")

if 3 == 4: print("it was true")

if 3 != 3: print("it was true")
else: print("it was false")

if 9 != 18: print("it was true")
else: print("it was false")

if "pig": print("it was true")
else: print("it was false")

if "": print("it was true")
else: print("it was false")

if 2 > 1 and 5 > 3: print("it was true")
else: print("it was false")

else: print("it was false")

else: print("it was false")

if 4 % 2 == 0: print("it was true")
else: print("it was false")

if 5 % 2 == 0: print("it was true")
else: print("it was false")

for i in range(7):
    if i % 3 == 2: print(i, "true")
    else: print(i, "false")
```
